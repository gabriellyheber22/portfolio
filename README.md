# Portfólio da Gabrielly

Portfólio pessoal feito com HTML, CSS e JavaScript.

## Como usar

Abra o arquivo `index.html` no navegador.

## O que personalizar

- Troque o texto da seção "Sobre mim".
- Coloque sua foto na pasta `images/`.
- Substitua os projetos pelos seus trabalhos.
- Atualize e-mail, Instagram e GitHub.
- Ajuste as cores no começo do `style.css`, se quiser.

## Publicar no GitHub Pages

1. Crie um repositório chamado `portfolio`.
2. Envie os arquivos deste projeto para o repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.
